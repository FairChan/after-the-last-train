# Underdog

浏览器里直接玩：**https://fairchan.github.io/after-the-last-train/**

俯视 2D 像素搜打撤。遥控一具租来的工壳钻进被机器占领的城市地铁网，一站站搜刮，赶在被拆成零件之前撤出来。

- 操作：WASD 移动，左键开枪，右键近战（按住蓄力重击；拿狙击类时按住是开镜），空格闪避（贴着躲开是完美闪避），Q/E 模块，G 型号技能，R 换弹，B 换弹种，F 交互 / 捡东西（地上的枪长按 F 直接换上），C 回血，V 护盾，Z 扔手雷（这三个键点按是用；按住再滚滚轮，换成背包里同类的别的，比如维修包换贴片、高爆换烟雾弹），X 释放电容（左下角带闪电的条，打中、击毁、完美闪避都会充，满了按 X：弹匣补满、整匣超级弹），Tab 背包，Esc 暂停，M 静音。按键都能在设置里改
- 离站：每一站都只能在站台上坐车离开。上面写着下一班车还有多久到，车进站停靠时走到站台下沿就上车，去下一站
- 撤离：只有线路尽头的撤离站（和两个走到旁边才发现的隐藏撤离点）能撤。在控制台呼叫接驳车，守一小会儿站台，车到了上车回据点；不想撤，就等普通班车去下一站
- 背包：Tab 打开，左边是脚边的东西，中间是你的机器人，四周是装备槽；把枪、近战、模块、背包拖到槽上就换上
- 线路（新开的档）：每个线路交点都是换乘站，还有一条内环线，岔路多；沿线不会一连好几站都是普通站，事件、精英、休整、商人、宝藏站穿插其中
- 线路主题：每条线是工业线 / 商业线 / 旧城线之一，配色、房间、特有敌人（焊工机 / 橱窗假人 / 野狗机）和特产都不一样；车站有六种骨架（标准、长厅、双厅、环厅、深埋、塌方）
- 观感：主角机器人有明暗和厚度；用药、换弹、换枪、扔手雷、捡东西、进站开机都有动作；交易行买的东西会飞进仓库；主菜单用上下键也能选
- 内容（M5）：18 把枪（喷火枪、榴弹发射器、转管机枪、追踪枪、钩爪枪……）、10 种近战、14 个模块（自动炮台、僚机、闪现、钩索……）、20 个被动；16 种敌人，沦陷区的虫巢、检查站、数据中心里住着镇守首领（蜂后、铁闸、档案官）；水淹站、停电站、调度中心、旧货运站；站里有时会停电、来一群迁徙的小机器、空投补给、对手小队追进来、开过一列幽灵列车；8 个型号（新的鹰眼、蜂巢）；开始菜单城市种子旁边的"随机"换一座城市
- 画面和声音（M6）：6 首配乐跟着场景换（据点、线路图、安全、危险、撤离战、首领），设置里能调音乐音量；新加旧城瓷砖、混凝土隧道、冷光机房三种车站环境；敌人会呼吸、蓄势、挨打时一缩，被击毁时压扁散掉
- 手柄：左摇杆走、右摇杆瞄、RT 开枪、LT 近战、B 闪避、A 交互，菜单里方向键挪、A 确认、B 返回。设置里有全屏、色弱模式、游戏速度、手柄瞄准辅助；据点"菜单"里有 30 个成就
- 英文：设置最上面"语言 / Language"选 English，界面、物品、剧情都换成英文（网址加 ?lang=en 也行）
- 子弹袋和超级弹：配装页 / Tab 背包里有 5 格子弹袋，只放弹药，换弹从左到右拿（拖动排顺序）；近战打中、完美闪避给电容充电，蓄满时弹匣一下补满、整匣变成穿透的超级弹
- 第一次开新档会问要不要走一遍新手教学（约 3 分钟）；以后在据点"菜单"里能重玩
- 主线：翻柜子时留意旧纸片。据点的"人物"页有林桥、阿隼、陆峥的对话和委托，"线索"页是线索日志和下一步；12 条线索拼出一列失踪的末班车
- 成长：据点"设施"页升级工作台、医疗室、情报站、仓库，工作台能做枪械配件和机器人改装件；"委托"页每天有新委托；"配装"页给枪装配件（改枪台）；机库卡片上的"改装"进机库改装台，给型号装改装件，装上的改装件会画在机器人身上。装上的配件和改装件随工壳损毁一起丢
- 进度自动保存在浏览器里（三个存档位），可以在据点"菜单"里导出存档文件；清理浏览器数据会清掉存档，记得导出备份
- 纯 JavaScript + Canvas，无引擎、无构建
